# Open the vault

1. Install Obsidian and select **Open folder as vault**.
2. Choose the repository's `obsidian-vault/` folder.
3. Open [[00 - Start Here]].
4. Navigate with wikilinks, backlinks, graph and YAML properties. No third-party plugin is necessary.

This folder has no private logs, SSH keys, accounts, SQLite database, trained model, or credentials. Do not add them to the public repository.
