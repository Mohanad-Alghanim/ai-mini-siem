# Dashboard Guide

| Screen | Use |
|---|---|
| Overview | See stored counts/charts |
| Security Events | Explore historical events; separate sanitized SSH lab tab |
| Predictions | Filter Normal/Anomaly, model, batch and IP |
| Alerts | View stored anomaly alerts; not independently verified intrusions |
| Data Sources / System Information | Review model provenance and offline limitations |

Refresh rereads the stored database. It does **not** ingest events or execute AI. A negative Isolation Forest decision score means Anomaly, not an attack probability. See [[02 - Kali Quick Start]].
